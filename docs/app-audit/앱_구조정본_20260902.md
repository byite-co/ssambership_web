## 6. 특별 확인 항목 답변

### 6-1. 연결노트 데이터 구조 ★

**결론: 한 작성자가 한 방에 노트 1건을 계속 고쳐 쓰는 "단일 편집" 구조다. 누적(append)이 아니다.**

| 확인 항목 | 코드 사실 | 근거 |
|---|---|---|
| 여러 건 생성인가, 한 건 수정인가 | **한 건 수정.** `upsertMyNote(roomId, body)`는 `connection_notes`에서 `mentor_student_room_id = roomId AND author_id = 내 uid`인 행을 `updated_at desc`로 조회해, 있으면 최신 1건을 **UPDATE**(`body`, `updated_at`), 없으면 **INSERT** 1행 | `lib/features/question_room/data/question_room_write_repository.dart:194-248` |
| 저장 시 INSERT/UPDATE | 기존 행 있음 → `.update({'body','updated_at'}).eq('id', 최신행)` / 없음 → `.insert({'mentor_student_room_id','author_id','author_role','body'})`. 중복 행(2건 이상)이 있으면 최신 1건만 갱신하고 나머지는 best-effort `delete()`(실패 무시) | 같은 파일 `:203-235`, `:236-247` |
| 조회 시 몇 건 | 방 전체 행, **limit 없음**, `updated_at desc` | `question_room_read_repository.dart:258-265` `notes(roomId)` |
| 화면이 쓰는 건수 | 내 노트 = `authorId == uid`인 행 중 **첫 1건**을 편집기 텍스트로 시드(`mine.first.body`). 상대 노트 = 나머지 행을 `createdAt` 오름차순 카드로 전부 표시. 방 홈 미리보기도 "최근 멘토 노트 1건"(`mentor_room_home_screen.dart:48-54`), "내 노트 1건 + 학생 노트 1건"(`student_room_home_screen.dart:56-65`)만 사용 | `connection_notes_screen.dart:131-144, 152-166` |
